Verificação de Headers

Abra esta página junto com a página de suporte e execute o script abaixo no console da página de suporte:

// Cole este código no console da página /suporte
const headers = document.querySelectorAll('header');
console.log('Número de headers:', headers.length);
headers.forEach((header, index) => {
    console.log(`Header ${index + 1}:`, header);
    console.log('  - Classes:', header.className);
    console.log('  - Texto:', header.textContent.substring(0, 100));
    console.log('  - Parent:', header.parentElement?.tagName);
});
