# Explicação: Coleção Ativa

## 🎯 O QUE É "COLEÇÃO ATIVA"?

A coleção ativa é a coleção que você escolhe como **FAVORITA/PRIORITÁRIA**.

Escolher uma coleção como ativa significa:
- ✅ Personagens DESSA coleção custam 200 coins (preço mais barato)
- ✅ Personagens de OUTRAS coleções custam 240-450 coins (preço mais caro)

**NÃO significa:**
- ❌ Você vai receber só dessa coleção
- ❌ Você é obrigado a escolher dessa coleção
- ❌ Sistema agenda automaticamente dessa coleção

## 💡 ANALOGIA SIMPLES

### É como um programa de fidelidade de supermercado:

```
Você escolhe SUPERMERCADO A como favorito:

SUPERMERCADO A (Favorito):
- Arroz: R$ 20 ✅ (Preço de sócio)
- Feijão: R$ 10 ✅ (Preço de sócio)
- Macarrão: R$ 5 ✅ (Preço de sócio)

SUPERMERCADO B (Não é favorito):
- Arroz: R$ 24 ⚠️ (Preço normal)
- Feijão: R$ 12 ⚠️ (Preço normal)
- Macarrão: R$ 6 ⚠️ (Preço normal)

Você PODE comprar no Supermercado B, mas paga mais caro!
```

## 🎯 RESUMO

**"Coleção Ativa" = "Coleção Favorita" = "Coleção com Desconto"**

Quando você escolhe uma coleção como ativa:
- ✅ Personagens dessa coleção ficam mais baratos (200 coins)
- ✅ Você economiza coins se escolher dessa coleção
- ✅ Mas você PODE escolher de outras coleções (pagando mais)

**Exemplo prático:**

```
João tem 600 coins
João escolhe Naruto como ativa

OPÇÃO 1: Só da ativa (mais barato)
- Naruto (200) + Sasuke (200) + Kakashi (200) = 600 coins ✅
- Gasta tudo, não sobra nada

OPÇÃO 2: Mix (mais caro)
- Naruto (200) + Goku (240) + Vegeta (240) = 680 coins ❌
- Faltam 80 coins, precisa comprar extras

OPÇÃO 3: Nenhuma da ativa (muito caro)
- Goku (240) + Vegeta (240) + Piccolo (240) = 720 coins ❌
- Faltam 120 coins, precisa comprar extras
```

## ❓ POR QUE EXISTE "COLEÇÃO ATIVA"?

### Vantagens para o Cliente:
1. **Economia**: Paga menos pelos personagens da coleção favorita
2. **Flexibilidade**: Pode escolher de outras coleções se quiser
3. **Controle**: Sabe exatamente quanto vai gastar

### Vantagens para o Negócio:
1. **Fidelização**: Cliente cria vínculo com uma coleção
2. **Upsell**: Cliente quer personagem de outra coleção, compra coins extras
3. **Previsibilidade**: Maioria escolhe da coleção ativa (mais fácil planejar produção)

## 🔄 COMO FUNCIONA NA PRÁTICA

### Passo a Passo:

```
1. Cliente assina Trimestral
   → Recebe 600 coins

2. Cliente escolhe NARUTO como ativa
   → Naruto fica 200 coins
   → Outras coleções ficam 240-450 coins

3. Cliente escolhe personagens:
   
   MARÇO:
   - Opções: Naruto (200), Goku (240), Homem-Aranha (300)
   - Cliente escolhe: Naruto (200 coins)
   - Saldo: 400 coins
   
   ABRIL:
   - Opções: Sasuke (200), Vegeta (240), Homem de Ferro (300)
   - Cliente escolhe: Vegeta (240 coins)
   - Saldo: 160 coins
   
   MAIO:
   - Opções: Kakashi (200), Piccolo (240), Capitão América (300)
   - Cliente tem: 160 coins
   - Kakashi custa: 200 coins
   - Faltam: 40 coins ❌
   - Cliente compra: 40 coins extras (R$ 20)
   - Cliente escolhe: Kakashi (200 coins)
   - Saldo: 0 coins
```

Ficou claro agora? 

**"Coleção Ativa"** é só um jeito de dizer:
- "Qual coleção você quer que seja mais barata?"
- "Qual coleção você quer ter desconto?"
- "Qual coleção você quer pagar 200 coins ao invés de 240-450?"

Você PODE escolher de qualquer coleção, mas a ativa é mais barata! 💰
